# Wanderlust - Travel Destination Platform

Wanderlust is a travel destination platform built with Next.js and React. It allows users to explore travel destinations, view destination details, and access authentication features.

## Features
- Browse travel destinations
- View destination details
- User registration and login
- Responsive user interface
- Destination management interface

## Technologies Used
- Next.js
- React
- Tailwind CSS
- HeroUI
- Better Auth

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/JannatJimu/wanderlust-client.git
   ```

2. Navigate to the project directory:
   ```bash
   cd wanderlust-client
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Create a `.env.local` file and configure the required environment variables.

5. Start the development server:
   ```bash
   npm run dev
   ```

6. Open `http://localhost:3000` in your browser.

## Environment Variables

Configure the environment variables required by the application, including the backend server URL and authentication settings.
